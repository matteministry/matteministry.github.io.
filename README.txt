ANTES DE PUBLICAR
1. En script.js cambia las URL de ejemplo por los enlaces oficiales.
2. Sustituye el número de WhatsApp en formato internacional, sin + ni espacios, por ejemplo 506XXXXXXXX.
3. Cambia el correo de ejemplo por el correo oficial.
4. Revisa que cada enlace abra la página correcta.
No publiques hasta completar estos datos.

ABRIR EN MAC
1. Descomprime el ZIP.
2. Abre la carpeta y haz doble clic en index.html para verlo en Safari.
3. Los cambios de diseño se hacen en styles.css; los enlaces y contactos se cambian en script.js.

PUBLICAR CON GITHUB PAGES (cuando todo esté revisado)
1. Crea una cuenta en github.com si no tienes.
2. Crea un repositorio llamado matte-ministry.
3. Sube index.html, styles.css, script.js y la carpeta assets/ al nivel principal del repositorio.
4. Ve a Settings > Pages.
5. En Build and deployment selecciona Deploy from a branch.
6. Elige main y /(root), y guarda.
7. GitHub mostrará la URL pública cuando termine de publicar.

DISEÑO ACORDADO
- Estilo limpio y moderno; carbón, gris cálido, crema y amarillo del logo en pequeños acentos.
- Se utiliza el logo oficial y las portadas que compartiste.
- No se incluye apartado de imágenes/ensayos ni tienda/merchandising.
